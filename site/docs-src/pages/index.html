Vano documentation

Vano is a free, open source disk analyzer for Linux, Windows and macOS. It scans a folder, a disk or a WSL 2 distribution in seconds, shows where the space goes as a treemap, rings or a ranking, and recommends what can be removed safely.

What Vano is

A disk fills up slowly and then all at once. Vano answers two questions: what takes the space, and what of it can go. It reads the size of every file with a parallel scanner, so a home folder of hundreds of thousands of files takes well under a second with a warm cache, and draws the result on the GPU, with no web view behind it.

Then it looks for things that are safe to remove: package caches, build outputs, browser caches, old installers, virtual disks. Each recommendation says what it is and whether the tool that made it recreates it by itself.

What Vano never does

  • It never removes anything without a confirmation, which shows what goes and asks whether to move it to the Trash, where it can be put back, or to delete it for good.
  • It never reads the contents of your files, only their sizes and dates.
  • It never needs an account, and sends no telemetry. The only network request is the optional update check.
