Recommendations

Vano looks for well known space eaters and sorts them in two groups: Safe, which their tool recreates by itself, and Review, which you may still need.

How Vano decides

The rules are conservative. A match is either a well known location (~/.npm, ~/.cache/pip) or a folder with a given name next to the file that proves what it is: target next to Cargo.toml, node_modules next to package.json. The outermost match wins, so recommendations never overlap, and Vano never looks inside one. Locations follow each system: the same cache lives in different places on Linux, macOS and Windows.

Safe

Caches and build outputs. Removing them loses nothing: the tool downloads or builds them again when it needs them, at the cost of some time the next time. Safe recommendations start selected.

Information only

Some recommendations cannot be removed from Vano, because their space only comes back through their own tool. The virtual disk of a WSL distribution is one: Vano explains how to shrink it instead. To clean inside a distribution, scan it.
