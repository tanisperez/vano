FAQ

Can Vano delete something important?

Only what you confirm. Safe recommendations are caches and build outputs their tools recreate; Review ones need your look. Every removal shows what goes first, and the Trash lets you put it back.

Does Vano send my data anywhere?

No. It reads file sizes and dates on your machine and keeps everything there. The only network request is the optional update check, which sends no identifiers.

Why is the scan so fast?

Many threads read folders in parallel with the fewest system calls possible, and the interface is drawn on the GPU. A warm home folder of 780,000 files takes under half a second.

Why does Vano show less used space than my disk does?

Vano counts the files it can read. The difference is in Not scanned: other users, system folders, file system metadata, and on ext4 the space reserved for the administrator.

Is it free?
