Installation

Vano is a single desktop application with no account and no sign in. Download it for your system, or install it with the Linux install script to get updates from the app.

System requirements

WindowsWindows 10 and 11, 64 bitInstaller (-setup.exe), portable zip (-portable.zip)

Every file is published on the latest release page on GitHub, with its SHA-256 checksum. The download page links to the right one for each system.

Linux

Install script

On any distribution, one command installs the latest release for your user, with no sudo:

```shell $ curl -fsSL https://vano.tanis.codes/install.sh | bash ```

The script downloads the tarball of the latest release, checks it against the release's SHA256SUMS and installs it under ~/.local: the program in ~/.local/bin/vano, and the menu entry and the icons under ~/.local/share. It writes the list of the files it installed to ~/.local/share/vano/installed-files, so updating and uninstalling touch exactly those.

A copy installed this way updates itself from the app. Running the same command again also updates it.

To pass options, put them after bash -s --:

```shell $ curl -fsSL https://vano.tanis.codes/install.sh | bash -s -- --uninstall ```
OptionWhat it does
--version X.Y.ZInstalls that release instead of the latest one.
--prefix DIRInstalls under DIR instead of ~/.local. A system folder such as /usr/local needs sudo bash, and then updates come from running the command again.
--uninstallRemoves the files the script installed. Your settings, saved scans and logs stay.
--purgeWith --uninstall, also deletes your settings and logs (see Files and folders).
--tarball FILEInstalls from a release tarball already on disk. The in-app updater uses it after verifying the file.
-h, --helpShows the options.

The script refuses to install a second copy when a package manager already installed Vano in /usr/bin: remove the package first.

Debian and Ubuntu

```shell $ sudo apt install ./vano_*_amd64.deb ```

Fedora and openSUSE

```shell $ sudo dnf install ./vano-*.x86_64.rpm $ sudo zypper install ./vano-*.x86_64.rpm ```

Arch Linux

Also for CachyOS, Manjaro and EndeavourOS:

```shell $ sudo pacman -U ./vano-*-x86_64.pkg.tar.zst ```

To update a package, install the package of the new version the same way. The app does not offer updates in a copy a package manager owns.

Tarball

The tarball has a /usr-like layout: the binary in bin/, the desktop entry and the icons in share/, and the install script at the top.

```shell $ tar -xzf vano-*-linux-x86_64.tar.gz $ ./vano-*/bin/vano ```

Windows

The installer is for your user only and needs no administrator rights. It puts Vano in %LOCALAPPDATA%\Programs\Vano, adds it to the Start menu and, unless you untick it, to your PATH, so vano works in any new terminal. It updates itself.

The portable zip holds only vano.exe. It needs no installer, writes nothing next to itself and scans WSL 2 distributions like the installed copy. It does not update itself: the app tells you when there is a new zip.

macOS

Open the disk image and drag Vano to Applications. It updates itself.

First launch

Vano is not code signed yet, so your system asks once before opening it. Updates are not affected.

  • macOS: if it says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Vano.app once.
  • Windows: if SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Updates

Ten seconds after it starts, Vano checks once whether a newer version exists. It downloads it in the background and verifies its checksum, then shows Restart in the status bar. Nothing installs without that click. You can turn the check off, or check by hand, in Settings, About.

When you restart to update, Vano checks again first, so it always installs the latest release, even if the window was open while two of them came out.

Build from source

Vano builds with the stable Rust toolchain. Clone the repository and run cargo run --release. The README lists the system libraries each platform needs.
