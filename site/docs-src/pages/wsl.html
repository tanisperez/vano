WSL 2 distributions

On Windows, Vano lists your WSL 2 distributions and scans each one from inside, natively, in seconds.

On the home screen

The Linux (WSL 2) section lists every WSL 2 distribution: its name, a Docker tag for Docker Desktop's own, whether it is running, the space used inside (only when it runs, asking would start it) and the size of its virtual disk on your Windows disk. Double click one, or select it and click Scan.

How the scan works

Reading a distribution's files from Windows, through \\wsl$, is slow. Vano carries a small Linux program inside vano.exe, vano-wsl, and runs it in the distribution with wsl.exe: it scans / natively and sends the result back. You install nothing in the distribution, and the portable copy works too.

  • A stopped distribution starts for the scan, which adds a few seconds.
  • It scans as your default user of the distribution, so folders only root can read show as Not scanned.
  • It stays on the distribution's own disk: /mnt/c and other mounts are left out.
  • The recommendations are those of Linux, with your home folder inside the distribution.

The first scan writes vano-wsl to %LOCALAPPDATA%\Vano\wsl; the uninstaller removes it.

Removing files

Files are deleted inside the distribution, natively, and always for good: the Recycle Bin cannot take them. The same rules apply as for any permanent deletion.

The virtual disk does not shrink

Each distribution keeps its whole system in an ext4.vhdx that grows as files are added and does not shrink by itself when they are deleted. Removing files frees space inside the distribution; to give it back to Windows, compact the virtual disk with the tools WSL documents, such as its sparse mode.
