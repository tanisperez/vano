What to scan

Anything with files: your home folder, a whole disk, an external disk, a folder, or a WSL 2 distribution.

Home folder

Your files, projects and caches. It is where most recommendations are, and the fastest scan.

Disks

The system disk is / on Linux and macOS (File system, Macintosh HD) and C: on Windows. Other disks are listed with their label: internal ones, USB disks and memory cards. Vano leaves out what is not a disk you would clean: boot partitions, snaps, container layers, network shares, and the extra mount points of one btrfs disk.

A scan stays on one file system: it lists a disk mounted inside the folder, but does not enter it. Scan that disk on its own.

Any folder

Choose a folder…, or Ctrl O (⌘ O on macOS), opens the system folder picker. A network share works too, but goes as fast as the network does.

WSL 2 distributions

On Windows, each distribution is scanned from inside, natively. See WSL 2 distributions.

What Vano counts

  • The space files take on disk (allocated bytes), not their apparent length. A sparse file counts what it really uses.
  • A file with several hard links counts once.
  • Symbolic links count their own tiny size, never what they point to.
  • What Vano cannot read (folders of other users, system folders without permission) is shown as Not scanned. On macOS, system folders need Full Disk Access (see Troubleshooting).

Every finished scan is saved, so Open results brings it back after a restart. The last four are kept.
