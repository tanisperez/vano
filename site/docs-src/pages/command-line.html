title: Command line description: The vano command: list disks, scan a folder, clean up caches, list WSL distributions, with JSON output and exit codes for scripts. ---

Command line

The same vano program runs commands in the terminal. Without a command it opens the window.

On Windows, the installer adds Vano to your PATH, so vano works in any new terminal. With the Linux install script it is in ~/.local/bin.

vano drives

The connected disks, as the home screen lists them.

```shell $ vano drives MOUNT LABEL KIND FS USED / NVMe SSD, system ext4 249 GB of 501 GB 50% /run/media/ana/Backup Backup External HDD exfat 1.2 TB of 2.0 TB 60% ```

--json prints the same as JSON, with the sizes in bytes.

vano scan

Scans a folder or a disk, the home folder when left out, and prints the biggest entries and the recommendations.

```shell $ vano scan ~/dev --top 5 ~/dev: 17.6 GB in 26,672 files, scanned in 0.1 s Biggest 17.6 GB target/ 26.0 MB .git/ Recommendations Safe 17.6 GB Rust build output ~/dev/target ```
OptionWhat it does
--top NHow many of the biggest entries to list (10 by default).
--jsonPrints JSON: totals, the biggest entries and every recommendation with its paths.
--cross-file-systemsAlso enters other file systems mounted inside the folder.

vano clean

Scans a folder, the home folder when left out, and removes its Safe recommendations. Review recommendations are never removed from the terminal: they need someone to look at them in the window.

It lists what it would remove first, then:

  • in a terminal, asks before removing anything;
  • with --dry-run, or with no terminal to ask (a script, a pipe), only lists;
  • with --yes, removes without asking.

Items go to the Trash unless you pass --permanent. --json prints the outcome as JSON.

```shell $ vano clean ~/dev --dry-run 17.6 GB to clean in ~/dev: Safe 17.6 GB Rust build output ~/dev/target Nothing was removed. Run vano clean --yes to move them to the Trash. ```

vano wsl list

On Windows, the WSL 2 distributions: running or stopped, the size of the virtual disk and, for running ones, the space used inside. The default one has a *. --json prints JSON.

vano completions

Prints the completion script of bash, zsh, fish, elvish or powershell:

```shell $ vano completions bash > ~/.local/share/bash-completion/completions/vano ```

Exit codes

CodeMeaning
0Done, a dry run included.
1Something failed: a path that cannot be read, items that could not be removed.
2The command line is wrong.
3vano clean found nothing to clean.

The JSON field names are stable: new versions may add fields, never rename or remove them.
