Removing files

Nothing goes without a confirmation. It shows what goes and asks how: to the Trash, which you can undo, or for good.

What you can remove

  • The selected recommendations, with Delete under the list.
  • One folder or file of the explorer, from its details panel (right click it).

Move to Trash

Items go to the system Trash (the Recycle Bin on Windows), where they can be put back. Right after, the toast's Undo puts them back for you, on Linux and Windows. The Trash keeps their space until you empty it, so the disk does not get freer yet.

Many thousands of files can take a while to move: the confirmation warns you from 20,000 files.

Delete permanently

Items are deleted for good, one file at a time, so the progress shows and Stop halts before the next file. It is faster than the Trash and frees the space at once. It cannot be undone.

A permanent deletion never follows a symbolic link and never enters another file system mounted inside a folder: it removes what the scan counted and nothing it reaches by accident.

Inside a WSL distribution

The Recycle Bin cannot take the files of a WSL distribution, so there the confirmation only offers to delete them for good. See WSL 2 distributions.

When something stays

An item that could not be removed stays in place, and a report says which and why: a file in use, a permission, or a Recycle Bin that refuses something too big. The rest of the batch goes on.
