Download Vano

Free and open source. Pick your system below. Every file is attached to the latest release on GitHub, with its SHA-256 checksum.

  • Windows

    Windows 10 and 11, 64 bit. The installer is for your user only, needs no administrator rights and updates itself. The portable zip needs no installer at all, for machines where installing is not allowed.

    Download the installer File Vano-…-windows-x86_64-setup.exe Download the portable zip File Vano-…-windows-x86_64-portable.zip

  • macOS

    Apple silicon (M1 and later). Drag Vano to Applications. Updates itself.

    Download the disk image File Vano-…-macos-arm64.dmg

  • Linux

    x86_64. A .deb for Debian and Ubuntu, an .rpm for Fedora and openSUSE, and a tarball for everything else.

    Download a package Files .deb, .rpm, .tar.gz
Linux

Install the package

From the folder you downloaded it to. To update, install the package of the new version the same way.

Debian and Ubuntu apt

apt resolves the dependencies of the downloaded file.

$ sudo apt install ./vano_*_amd64.deb

Fedora and openSUSE dnf, zypper

The same file works on both.

# Fedora
$ sudo dnf install ./vano-*.x86_64.rpm

# openSUSE
$ sudo zypper install ./vano-*.x86_64.rpm

Any distribution tar.gz

The tarball has a /usr-like layout: the binary in bin/, plus the desktop entry and the icons in share/.

$ tar -xzf vano-*-linux-x86_64.tar.gz
$ ./vano-*/bin/vano
First launch

A note on unsigned builds

Vano is not code signed yet, so your system asks once before opening it. Updates are not affected.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/Vano.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

Vano builds with the stable Rust toolchain. Clone the repository and run cargo run --release. See the README for the system libraries each platform needs.
